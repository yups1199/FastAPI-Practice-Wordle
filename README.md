## 과제 내용 (1번으로 진행)
오늘의 과제는 "개인" 레포지토리에 간단한 FastAPI 서버 프로그램 구현하기 입니다.
아래 두 프로그램 중 하나를 골라 구현하셔도 좋고, 본인이 원하는 것을 구현해도 좋습니다.
실제 GUI와 프론트엔드를 구현할 필요는 없습니다. 프로그램을 만든다고 상상하며, 프로그램에 어떤 API가 필요할지 생각해보세요.

1. Wordle(워들): 서버에 변수로 저장된(DB가 없으니 문자열 하드코딩하셔도 좋습니다. 무작위 단어를 선정하는 것도 좋아요.) 단어를 맞추는 게임을 구현하세요. 숫자 야구와 비슷합니다.
   - 클라이언트로부터 단어 입력을 받고 각 자리의 알파벳이 1. 정답과 같은지, 2. 정답과 다른지, 또는 3. 정답 단어에는 들어 있지만 자리가 다른지를 반환하세요.
   - 단어 검사 구현이 어렵다면 해당 부분에 대해서는 제한적으로 AI를 사용해도 좋습니다. 과제의 목표는 FastAPI에 익숙해지는 것이니까요.
   - 원한다면, 단순 단어 wordle이 아닌 특정 주제에 대한 퀴즈 형식으로 구현해도 좋습니다(업다운 퀴즈 등). 주제는 자유에요!
   - 별도 엔드포인트를 통해 정답을 확인할 수 있도록 하세요.
   - 6번 연속으로 정답을 맞추지 못한다면 오류를 반환하세요. 무상태성 원칙은 지키면서요..

2. 길이 단위 변환 서비스: 클라이언트가 보내는 숫자를 목표 단위계에 맞춰 변환한 후 반환하세요.
   - 미터 단위를 야드/인치/피트로 변환할 수 있게 하세요. (힌트: 목표 단위계를 매개변수로 지정합니다.)
   - 마찬가지로, 야드, 인치, 피트 단위도 미터로 변환할 수 있게 하세요.
   - 원한다면 길이가 아닌 무게, 에너지, 부피와 같은 다른 주제를 골라도 좋습니다.

"간단한" 프로그램입니다!! 너무 거창한 것을 만들지 않아도 됩니다.
